Binary String Equality Recognition

Register Number: RA2411003010026

01 / Concept & Working Principle

A Turing Machine is a mathematical model of computation that uses a tape, read/write head and finite states to process symbols.

This machine recognizes the language L = {x#x | x ∈ {0,1}*}. It accepts two identical binary strings separated by exactly one # symbol.

Input Alphabet Σ = {0, 1, #}
Tape Alphabet Γ = {0, 1, #, X, Y, B}
Marking Technique X = processed 0
Y = processed 1
B = blank

Working Algorithm

  1. Find the first unmarked left-side symbol.
  2. Mark 0 as X or 1 as Y.
  3. Move right across the # separator.
  4. Find the next unmarked right-side symbol.
  5. Compare and mark it if matching.
  6. Return left and repeat.
  7. Accept only when both strings are fully matched.

Example: 101#101 is accepted. 101#100 is rejected. # is accepted because x may be empty.
